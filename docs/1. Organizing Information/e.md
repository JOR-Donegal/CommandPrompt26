# Copying, Moving and Deleting Files

Make sure you are in the directory called __CLI__. The format of the copy command is __copy__ _source destination_

This will copy from an existing file (source) to a new file (destination) leaving the original file where it was.

To move a file in DOS, the format of the command is __move__ _source destination_

This will move an existing file (source) to a new location (destination), removing the original file.

To delete a file in DOS, the format of the command is __del__ _filename_

This will delete a the file called filename
